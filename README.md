# 💄 LizzyJay Cosmetics Branding & OpenCV Project

## 🚀 Overview

**LizzyJay Cosmetics Branding & OpenCV Project** is a unique combination of **Graphic Design** and **Computer Vision**. The project demonstrates both creative branding skills and technical image processing concepts.

The branding section focuses on creating a professional identity for a cosmetics brand, while the OpenCV section showcases fundamental image processing techniques using Python.

This project was developed as part of my BCA learning journey to explore the intersection of **design, technology, and computer vision**.

---

## 🎯 Project Objectives

* Create a complete cosmetic brand identity.
* Design professional marketing assets.
* Apply design principles such as color theory and typography.
* Learn image processing using OpenCV.
* Implement various computer vision operations.
* Analyze and visualize image transformations.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Python 3.x installed
* pip package manager

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/lizzyjay-cosmetics-opencv.git
```

Move into the project directory:

```bash
cd lizzyjay-cosmetics-opencv
```

Install required dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

### Resize, Rotate, Crop & Blur Operations

```bash
python opencv/resize_rotate_crop_blur.py
```

### Edge Detection

```bash
python opencv/edge_detection.py
```

### Color Processing

```bash
python opencv/color_processing.py
```

### Brightness & Contrast Enhancement

```bash
python opencv/brightness_contrast.py
```
